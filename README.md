## 執行與維護

直接開啟 `index.html`，或在此資料夾執行：

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

瀏覽 `http://127.0.0.1:8765`。修改 `index.html` 後推送 `main`；GitHub Pages 從 `main` 根目錄發布，無建置步驟。
